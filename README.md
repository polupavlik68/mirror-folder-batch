# Пакетная обработка папок

Две ноды для ComfyUI. Они обходят папку вместе со всеми подпапками, отдают в граф по одной фотографии и сохраняют результат в другую папку с тем же именем и теми же подпапками.

Между ними ставится ваша обработка. Одна нода на оба конца не подходит: картинка должна выйти до обработки и вернуться после неё.

## Установка по ссылке

Так ставят почти все кастомные ноды.

1. Опубликуйте эту папку как публичный репозиторий на GitHub. В корне должны лежать `__init__.py`, `web` и этот файл.
2. В ComfyUI откройте **Manager → Custom Nodes Manager → Install via Git URL**.
3. Вставьте ссылку `https://github.com/polupavlik68/mirror-folder-batch`.
4. Полностью перезапустите ComfyUI.

Manager клонирует репозиторий в `custom_nodes`. После перезапуска в меню нод появятся **Пакетная обработка** и **Сохранить в папки**.

Поиск в каталоге Manager подхватывает репозиторий отдельно, через [Comfy Registry](https://registry.comfy.org/). Для установки по прямой ссылке реестр не нужен.

## Как соединить

```
Пакетная обработка
  image          → ваша обработка → image          Сохранить в папки
  relative_path  ----------------------------→ relative_path
  output_folder  ----------------------------→ output_folder
```

**Batch count** оставьте 1. Нода сохранения сама ставит следующее фото в очередь, поэтому папка из тысячи файлов обрабатывается одним Run.

## Пакетная обработка

Берёт следующее фото, для которого в папке результата ещё нет файла.

- Читает все подпапки. Картинки: png, jpg, jpeg, webp, bmp, tif, tiff.
- **пропускать готовые** включено по умолчанию. Уже сохранённый файл не генерируется заново. Если прервать очередь, следующий Run продолжит с первого неготового.
- **длинная сторона** по умолчанию 2048. Фото больше уменьшается, фото меньше не увеличивается. Стороны выравниваются до кратности 32. Значение 0 оставляет размер как есть.
- Папка результата должна лежать снаружи входной папки.
- На ноде есть обзор папок и оценка оставшегося времени. Среднее появляется со второго фото.
- Кнопки обзора открывают окно выбора папки на том компьютере, где запущен ComfyUI.

Выходы: `image`, `relative_path`, `output_folder`.

## Сохранить в папки

Кладёт результат в `папка результата / относительный путь`. Подпапки создаются сами, имя файла остаётся исходным.

- jpg и jpeg пишутся с качеством из **jpeg quality** (по умолчанию 95) и без цветового прореживания.
- webp пишется с тем же качеством.
- Остальные расширения сохраняются как png.
- Прозрачность перед записью убирается: JPEG её не хранит.

После успешного сохранения, если очередь пустая, нода ставит следующий файл сама.
